# Om Mahajan — Data Science Portfolio

A responsive personal portfolio starter built with plain HTML, CSS, and JavaScript.

## Open it
1. Extract `om_data_science_portfolio.zip`.
2. Open `index.html` in a browser, or open the folder in VS Code.
3. Optional: use the VS Code Live Server extension for live preview.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your professional email.
- Replace the generic LinkedIn and GitHub URLs with your own profiles.
- Add real GitHub/dashboard links to each project.
- Verify internship dates, education dates, and certification names.
- Confirm each tool/method shown for a project reflects what you actually used.
- Add a resume PDF only when you're ready to share it publicly.

## Files
- `index.html` — page content and sections
- `style.css` — dark theme, responsive layout, visual styles
- `script.js` — mobile navigation and current year

## Publish free
You can publish the folder with GitHub Pages. Create a GitHub repository, upload these three files to the repository root, then open **Settings → Pages** and choose the main branch and root folder. The site URL will be shown there once deployment completes.
